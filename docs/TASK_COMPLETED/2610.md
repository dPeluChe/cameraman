## 2026-10-01 — Review with the Swift skills, MCP hosted in the app

**Fixes from the review (PR #52, #53)**
- [x] Removed the `signal(SIGSEGV…)` crash handlers: they spawned a `Task` and awaited an actor, which is not async-signal-safe, and returning from SIGSEGV/SIGBUS re-runs the faulting instruction, so the app hung with no system crash log.
- [x] `project.json` writes are atomic.
- [x] PrivacyInfo DiskSpace reason corrected to `E174.1`.
- [x] Global hotkeys were stubs (`HotkeyManager` shadowed the Carbon calls and returned `noErr`); they now register through real Carbon. `Hotkey.shiftKey` was `0x2000` (`rightShiftKey`), now `0x0200`. Needs a manual check that they fire in the background.
- [x] Four stale or wrong tests repaired; `ProjectFilter.excludedTags` only filtered when `tags` was also set (PR #50).

**MCP in the app (PR #54, #55)**
- [x] `MCPServer` is transport-agnostic (`handle(message:)`), stdio is a thin loop over it, plus a loopback HTTP transport: bearer token, Host and Origin must be loopback, connection cap, request deadline, version negotiation.
- [x] `MCPHostService`: opt-in, token in the Keychain, port 8765 (clear error if taken, no silent fallback), Preferences section with Claude Code and Cursor snippets. Verified in the sandboxed Debug build.
- [x] `network.server` entitlement; `CameramanMCPCore` exposed as a library product and linked in the Xcode project.

**MCP tool audit (PR #56, #58)**
- [x] 43 → 37 tools: `list_overlays`/`list_adjustments` folded into `get_project`, `search_projects` into `list_projects`, `rename_project`+`set_tags` into `update_project`, `list_jobs` into `get_job_status`, `set_clip_audio_muted` into `edit_clip`.
- [x] MCP annotations; `edit_clip` and `set_track` no longer let a later success mask an earlier failure; descriptions corrected against the code.
- [x] `get_project` omits subtitles by default (`include` to add them); `suggest_*` results are readable and stored per job; `AIService` uses the store's directory.

**Agent has priority (PR #57)**
- [x] `AgentActivityCenter`: while an agent edits through the in-app server the editor freezes behind a notice, unsaved work is flushed first, and the editor reloads once after the agent goes quiet. `performEdit`, undo and redo refuse while frozen. Does not cover the stdio helper.
